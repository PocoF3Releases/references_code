# Claude Code reference workspace

Use the ready indexed search workflow above for both historical trees. This is
reference data, not the active Android 17 build. Preserve source bytes, licenses
and ready index bundles. Do not run `/init` to replace the curated instructions,
scan all sources or rebuild indexes just to start a session.

For local Alioth work, the active checkout is normally `~/evo`, with maintained
state in `~/evo/.workhub`. Resolve those paths before using them; a GitHub clone
alone grants no access to local dumps, device tools or credentials. See the
[shared Claude setup](https://github.com/PocoF3Releases/Agents.md/blob/main/operations/claude-code.md)
for workspace locations and Sonnet/Opus selection. There is no mandatory model,
plugin, hosted service or package install for the reference CLI.
